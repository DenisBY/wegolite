<objective>
**As a** player, **I want to** press H in the same frame that I dock, **so that** a jump can never start while I am docked and relaunching cannot commit a jump I did not restart.

Purpose: close the NAV-04 blocker in 06-VERIFICATION.md (gap G-2 residual). The sequential path (dock, then relaunch) is already closed by 06-08. When the dock command and the H press drain in the same frame, the begin case is gated only on the mode at the start of the step. The dock then sets the mode to docked, the begin starts a 1800-step countdown anyway, and the countdown tick never runs while docked. After launch and skipLaunch the tick resumes and commits a 46,656 s jump with no new key press. The verifier reproduced this in the container (CASE A).

Output: a one-condition live-mode gate in the sim's begin case, three unit cases in tests/sim/hyperspace.test.ts (the same-frame regression plus two controls), and no change to the dock owner, the tick gate, or the drain order.

Decision basis: D-06 as amended by the PROJECT.md Key Decisions row "Cancel an active hyperspace countdown when the ship docks" (added by 06-08). That row is awaiting owner ratification (06-VERIFICATION human item 3). This plan implements the amended behaviour and does not change the row.

Framing source: the user story above comes from the NAV-04 truth in 06-VERIFICATION.md. The ROADMAP phase Goal line is not written as a user story, so this plan does not derive its framing from it.
</objective>
