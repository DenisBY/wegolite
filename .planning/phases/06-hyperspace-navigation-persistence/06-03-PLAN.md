<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| content system name -> overlay | Names come from compiled content and cross into the DOM. |
| pointer/keyboard -> selection | A click or arrow chooses a system id that the session later commits. |
| 256 markers + 875 edges -> canvas | A per-frame repaint would exhaust the SwiftShader frame budget. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-08 | Tampering (XSS) | system name rendered in the overlay | high | mitigate | Every dynamic string uses `textContent`; the overlay sets no `innerHTML`; the name comes from the validated content catalogue, not the save string. |
| T-06-09 | Tampering | forged click/arrow selection bypassing the action layer | low | mitigate | Selection lives in the pure model/session; markers are non-focusable canvas pixels, not DOM controls; Enter commits only the model's selected id; the session resolves the id against the galaxy map. |
| T-06-10 | Denial of Service | 256 labels / 875 edges repainted per frame on SwiftShader | medium | mitigate | Paint on open, selection, range and resize only; skip `renderFrame` while the chart is open; the loop is opaque behind the overlay. No requestAnimationFrame loop. |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package-legitimacy gate + blocking human checkpoint for `[ASSUMED]`/`[SUS]` packages. This plan adds no package; Canvas2D is a platform API. |
