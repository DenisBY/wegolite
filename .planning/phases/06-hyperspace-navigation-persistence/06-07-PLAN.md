## Trust Boundaries

| Boundary | Description |

| arrival hash -> `applyWitchpointArrival` | A deterministic route pose is installed into the live sim |
| fixed-step docking -> ship pose | The disarmed clamp can rewrite a pose when it mistakes open space for the tunnel end |
| browser probe vs live state | The reload proof must sample after the resumed loop has run |
