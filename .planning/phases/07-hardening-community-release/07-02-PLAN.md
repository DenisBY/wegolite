<objective>
**As a** player whose GPU driver resets or whose tab goes to the background, **I want to** come back to the same paused game with my save untouched, **so that** a graphics hiccup or a hidden tab never costs me progress or corrupts my state.

Purpose: QUAL-05. Today a lost context is terminal: the handler at `src/main.ts:351-361` aborts every listener, disposes the session and shows the failure surface (research Critical Finding 3). This plan replaces it with the recovery policy the owner chose: stay paused, recreate render resources on restore, resume only by player action (D-15), and show the failure surface if no restore arrives within 10 seconds (D-16). It also proves, in the browser, that a hidden or stalled tab neither catches up simulated time in a burst nor writes a save.

Output: a DOM-free recovery state machine with unit tests, the session hooks and save guard, the probe field, a pause-overlay notice, and two browser specs.

Framing source: QUAL-05 and CONTEXT D-15 and D-16. The ROADMAP Phase 7 Goal line is not a user story.

Design facts this plan relies on (read this session in the three.js r187 source inside the `wegolite-ci` image, `node_modules/three/src/renderers/WebGLRenderer.js`): `onContextRestore` (line 1127) calls `initGLContext()` (line 444), which creates a fresh `WebGLProperties`, textures, attributes, geometries and program cache, and `render()` returns early while `_isContextLost` is true (line 1650). Every geometry, material and texture therefore re-uploads lazily on the first render after the restore. That resolves research assumption A1 for the upload path; the browser test still proves it by comparing draw calls and triangles. `renderer.info` is also recreated, so `probe.renders` restarts from the restore and tests must compare it relative to the restore, never across it.

Placeholder copy (D-16 open item): the notice and failure strings are placeholders owned by the owner. They live as exported constants in one module so the owner's wording replaces one file.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GPU/driver -> page | The browser can revoke the WebGL context at any time; the session must not step or save across that gap. |
| session -> IndexedDB | A write during recovery could persist a half-state (research Pitfall 9). |
| visibility/timers -> fixed-step loop | A long frame delta after a hidden or stalled tab must not become a burst of simulated time. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
