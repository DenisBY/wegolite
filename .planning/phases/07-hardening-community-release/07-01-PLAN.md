The test-enforced half (a request listener over the whole core loop) is plan 07-08.

Output: a Vite build plugin, the edited `index.html`, a post-build e2e spec, and updated source pins in the compliance and container-contract tests.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository root -> build output | Licence documents cross from the source tree into the distributed site; a missing or stale copy breaks the GPL and CC BY-NC-SA attribution duty. |
| shipped page -> network | Any runtime fetch, script or image from another origin would leave the static, offline-capable posture (QUAL-08). |
| shipped page -> user | The title and footer are the product identity and the source offer the user sees. |
