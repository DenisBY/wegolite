<objective>
Turn the tracer's placeholder bodies into a recognisably Oolite Lave: one procedural planet material with surface, clouds, polar caps, air rim and terminator; a sun disc with Oolite's real `corona_*` semantics; a deterministic `sky_n_stars` field; and a correctly assembled Coriolis whose four coplanar nodes do not z-fight.

Purpose: WORLD-03 is a visual-fidelity requirement that cannot be met by geometry alone, and WORLD-02's z-fighting risk is concentrated in the Coriolis layers. This plan owns the GPU-facing half of the scene while leaving the flight model (plan 04) and HUD (plan 05) untouched.

Output: `src/render/shaders/planet.glsl.ts`, the five body modules brought to v1 fidelity, the assembled system scene, and the shader/starfield/station tests plus the scene e2e assertions. No new assets, no new packages, no hand-edited generated content.

**Fidelity corrections carried explicitly:** `corona_flare` sets the corona radius (`R * (1 + 8 * flare)`, 1.2282R for Lave), `corona_hues` is a blend between two inner layers, and `corona_shimmer` is an animation speed — none of them is a brightness or a colour hue. The dock is at local `-Z` after the Phase 2 Z-negation.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| compiled planetinfo -> shader uniforms | Content numbers enter GLSL; a missing/NaN colour or fraction must not make the planet invisible or black |
| GLB scene graph -> renderer | Third-party node transforms and materials are cloned and drawn; a changed node/transform breaks docking landmarks |
| content star count -> GPU buffer | A tampered `sky_n_stars` could allocate unbounded GPU memory |
| runtime textures -> canvas | Procedural CanvasTexture data is generated locally, never fetched |
