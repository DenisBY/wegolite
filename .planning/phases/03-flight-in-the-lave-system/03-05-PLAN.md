<objective>
Complete the v1 flight HUD: the classic green-vector layout in a fixed 1920×1080 design space, a 25.6 km 3D scanner, compass, aegis indicator, speed/roll/pitch/fuel bars, clock, condition light and message line — all drawn from a plain read-only model on one Canvas2D overlay.

Purpose: FLGT-05 is the information layer the player reads while flying. Splitting pure projection/format maths from drawing is what makes it testable in Node without pixel diffing, and the fixed design space is what keeps the classic proportions on every window.

</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| sim state/events -> HUD model | Read-only simulation data becomes pixels and strings |
| app message strings -> canvas | Event-derived copy is drawn, never injected into the DOM |
| window/DPR -> canvas backing store | A hostile or extreme window size can allocate a huge backing store |
