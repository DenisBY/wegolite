<objective>
Make WebGL2 failure a first-class, visible path: extract boot from `main.ts`, catch every renderer/context failure, show an accessible DOM fallback, publish `ready:false`, and never start the RAF or draw a HUD over a dead canvas.

Purpose: WORLD-05 exists because the current boot throws into the console and leaves a blank page on a WebGL2-less browser. This plan closes that path without disturbing the Phase 1/2 probe contract or the content-manifest-before-renderer rule.

Output: `src/app/boot.ts`, `src/app/fallback.ts`, the fallback probe publication, the `main.ts`/`index.html` wiring, and `tests/e2e/fallback.spec.ts` plus a normal-path regression in `tests/e2e/precision.spec.ts`.
