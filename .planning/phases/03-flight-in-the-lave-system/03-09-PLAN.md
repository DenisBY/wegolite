<objective>
Prove and enforce the scene lifecycle: a `SceneManager` that swaps Lave for another system and disposes the old scene without leaking GPU resources, an `AssetCache` that owns the shared GLBs exactly once, and a `?test=1` hook that makes non-growth measurable.

Purpose: WORLD-04 is the phase's lifecycle requirement, and Phase 6 will swap systems for real. Without this plan the first hyperspace jump would either leak the old Lave or dispose the shared Cobra/Coriolis and turn the next system black.

Output: the hardened `SceneManager`, `SystemScene.dispose()` registry, `AssetCache` ownership, menu scene, probe memory counters and gated test hooks, plus `tests/app/dispose.test.ts` and `tests/e2e/dispose.spec.ts`.

**Ordering note:** this plan runs after the fallback plan because both edit `main.ts` and the probe. It is the last plan in the phase and ends with a full `docker compose run --rm verify`.
</objective>
