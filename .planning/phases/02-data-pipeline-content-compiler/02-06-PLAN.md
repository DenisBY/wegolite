<objective>
Write deterministic GLB bytes for the Cobra Mk III and the four-part Coriolis composite, applying Oolite's +Z-forward → Three −Z-forward conversion, preserving the authored corner order (the reflection alone yields glTF counter-clockwise), and preserving every source material value under `extras.oolite`.

Purpose: DATA-04 is the phase's highest-risk binary artefact. The conversion is provable rather than conventional — negating Z is a reflection (`det = -1`), and Oolite stores the negation of the authored-order right-hand normal, so the reflected authored order is already glTF's required counter-clockwise front face; reversing the corners would double-flip. This plan makes that proof an assertion on every emitted triangle, and keeps byte layout under our control so a dependency upgrade cannot re-baseline every committed binary.

Output: `tools/oolite-ingest/convert/glb.ts`, `public/models/cobra3.glb`, `public/models/coriolis.glb`, a bounds golden, and the manifest/provenance rows. Textures are referenced but not yet vendored — plan 07 closes that loop.
</objective>
