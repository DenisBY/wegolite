## Phase 16 decisions this plan implements

- **D16-08 (cheaper particle count):** the cloud draws at most `EXPLOSION_MAX_PARTICLES = 10` particles, Oolite's count at a detail level up to `DETAIL_LEVEL_SHADERS` (`OOExplosionCloudEntity.m:60-73`), not the authored 25: 80 instances for the whole pool instead of 200 and less overdraw per explosion, matching Oolite's own default-detail look. No burn-out cloud for an expiring wreck and no fragment sprites.
- **D16-21 (router widening):** `shipDestroyed` joins `ROUTED_EVENT_KINDS` with `["dockFeedback"]` (the presentation subscriber `laserFired` already uses), so `EVENT_SUBSCRIBER_ORDER` is unchanged; the arm reads `position` and `radius` only. `entityRemoved` stays unrouted. This is the widening Phase 15 recorded for Phase 16 (OD-2) and amends the session-order pins in the same commit.
- **D16-22:** the cloud uses the compiled `oolite-default-ship-explosion` setting; the flash uses the C constants of `OOFlashEffectEntity.m` (no plist entry exists for it).
- **Presentation only:** the layer draws no random value from a sim stream (its particles are seeded from `fnv1a32` of the event position and radius), holds no entity id, and is owned and disposed by the system scene, so a jump or a Load clears it.
