## Decisions this plan implements

- **D-03:** the blast is ported onto ships and the player, superseding the Phase 16 row "The explosion's blast pushes debris only" (D16-04 / OC-4).
- **PD-02 (blast half):** buoys move, so the blast pushes a buoy too (Oolite pushes every ship whose status `isInSpace` lists; the station's STATUS_ACTIVE is not listed, Entity.m:1033-1041, which is why it never moves).
- **Planner decision (fidelity, numbers corrected):** pods, plates and buoys are blast sources because Oolite's `becomeExplosion` deals momentum for every exploding ship (`ShipEntity.m:8121-8126`); the visible case is overlapping pods (a centre within the receiver's radius, the floored case), not a pod a few metres apart; the 18-03 blast fixtures carry both values.
- **Recorded divergence:** the player receives a blast push only in flight; Oolite's `isInSpace` lists STATUS_LAUNCHING (Entity.m:1033-1041), so Oolite also pushes a launching player, while Wegolite's scripted launch takes no push (review L284@b45e113).
