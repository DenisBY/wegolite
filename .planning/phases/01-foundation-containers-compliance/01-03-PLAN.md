5. `src/sim/loop.ts`: `export interface LoopResult { frames: number; steps: number; accumulator: number }` and `runToSteps(state, frames: readonly number[], inputAtTick: (tick: number) => InputFrame, targetSteps: number): LoopResult`. Loop while `steps < targetSteps`; throw `new Error("frame list exhausted before target step count")` when the frame list runs out; add `Math.min(frames[i++] ?? 0, MAX_FRAME_DELTA)` to the accumulator; inner loop while `acc >= DT && n < MAX_STEPS_PER_FRAME && steps < targetSteps` calling `step(state, inputAtTick(state.tick), DT)`; decrement the accumulator; when `n === MAX_STEPS_PER_FRAME` reset `acc = 0` (drop the backlog). Comment that the input log is indexed by TICK, not by frame, and that the loop stops on a tick count because 1/144 does not divide 1/120.
