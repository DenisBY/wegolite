Give the world lifecycle a leg-anchor counter, and pin two things before the first v3 write (SAVE-07; D-01, D-05, D-07, D-03): the world-seed cross-check vector, and a real v2 writer blob as a golden.

D-07 requires the cross-check vector to be pinned before any v3 save is written, because persisting the epoch makes the mix32 derivation one-way. The v2 writer is replaced in plan 11-02, so this plan is the last point at which a golden can be captured from it.
