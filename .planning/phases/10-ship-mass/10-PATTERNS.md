**Guard pattern** (dock-port.ts lines 63-75) - copy for non-finite vertex / no non-degenerate triangle / non-positive mass:
```typescript
function requireMesh(meshes: Readonly<Record<string, ParsedMesh>>, name: string): ParsedMesh {
  const mesh = meshes[name];
  if (mesh === undefined) {
    throw contentError("SCHEMA", `${SOURCE}/Models/${name}`, name, {
      excerpt: `the model set has no parsed mesh for "${name}"`,
    });
  }
  return mesh;
}
```

**Mesh input shape** (`tools/oolite-ingest/convert/dat.ts` lines 44-80): `Vec3 {x,y,z}`, `Face.vertices: [number, number, number]` (indices), `ParsedMesh.vertices: Vec3[]`, `ParsedMesh.faces: Face[]`. Take `mesh.vertices` and `mesh.faces[].vertices`; do not mutate (`repairWinding` mutates faces in place elsewhere).

**Core pattern:** no in-repo analog for the octree; use RESEARCH.md Pattern 1 (10 numbered rules) and the "split step" code example. Constants block should mirror dock-port's named-constant-with-citation style (`FIT_RATIO`, `EXPANSION_FACTOR`, lines 49-56): `kBaseOctreeDepth=5`, `kSmallOctreeDepth=4`, `kOctreeSizeThreshold=900`, `kOctreeSmallSizeThreshold=20`, `kMaxOctreeDepth=7`, `OCTREE_MIN_HALF_WIDTH=1.0`, `VOLUME_DEPTH_LIMIT=5`. All arithmetic via `Math.fround`.

**Analog:** `tools/oolite-ingest/convert/dock-port.ts` for the `Record<string, ParsedMesh>` consumer plus `requireMesh`; `tools/oolite-ingest/convert/npc-ships.ts` for the catalogue access and `fail()` helper.

**Catalogue lookup + fail pattern** (npc-ships.ts lines 68-87):
```typescript
function fail(key: string, detail: string): never {
  throw contentError("SCHEMA", NPC_SHIPS_PATH, key, { excerpt: detail });
}
const entry = catalogue.entries.find((candidate) => candidate.key === key);
if (entry === undefined) {
  return fail(key, `the compiled ship catalogue has no "${key}" entry`);
}
```
Density comes from `entry.extras["density"]` (default 1.0; same `typeof === "string"` narrowing style as npc-ships.ts lines 109-115). Subentities come from `entry.shipDef.subentities` (`SubentitySchema` in `src/content/schemas/ship.ts` lines 54-61: `subentity_key?`, `type?`, passthrough); skip `type === "flasher"`, recurse by `subentity_key` into the catalogue, sum in float32 in list order. Throw if `model_scale_factor` is present in `extras`.

## Shared Patterns

### Named build failure (`contentError`)
**Source:** `tools/oolite-ingest/content-error.ts` (used as `contentError("SCHEMA", path, key, { excerpt })`; see dock-port.ts lines 66-74 and npc-ships.ts lines 68-70)
**Apply to:** `octree.ts`, `ship-mass.ts`, any new guard (NaN vertex, no non-degenerate triangle, non-finite or non-positive mass, scale key present, missing mesh).

### Strict zod schema as the final gate
**Source:** `src/content/schemas/ship-npc.ts` lines 25-32 + `npc-ships.ts` lines 120-127 (`safeParse`, first issue becomes `fail(...)`).
**Apply to:** the `mass` field in both the NPC record and (optionally) the client catalogue entry.

### Deterministic emit
**Source:** `canonicalJson` (`tools/oolite-ingest/canonical/json.ts`), used at npc-ships.ts line 137 and ships.ts lines 516, 558. Store `Math.fround(value)` as the number; it round-trips.
**Apply to:** all mass emission. Never hand-edit `src/content/generated/*`; regenerate with `docker compose run --rm assets`, verify with `docker compose run --rm assets npm run assets:check`.

### Shared `models` object, no second in-place mutation
**Source:** `generate.ts` lines 144-162 (one `readModels` feeds `emitDockPort` and `emitModels`; `glb.ts` runs `repairWinding` in place). The octree must read vertices/faces without mutating them.

### Sim isolation
**Source:** `src/sim/hyperspace/countdown.ts` header; ESLint denies `src/content/ships*` imports from `src/sim`. Sim keeps a literal constant, pinned to the compiled number by a test.

### Verification commands (Docker only)
Quick: `docker compose run --rm test npx vitest run tools/oolite-ingest/convert/octree.test.ts tools/oolite-ingest/convert/ship-mass.test.ts tools/oolite-ingest/convert/npc-ships.test.ts tests/content tests/sim/hyperspace-blockage.test.ts tests/contract/fidelity.test.ts`; then `docker compose run --rm test`, `typecheck`, `lint`, `assets npm run assets:check`. No `verify-full`.
