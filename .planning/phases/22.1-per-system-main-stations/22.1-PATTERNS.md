## Shared Patterns

### Sim purity: data in, never a literal
**Source:** `src/sim/dock/geometry.ts:1-60` (`DockPortData` structural type) and `src/sim/world/layout.ts:70` doc comment.
**Apply to:** every `src/sim` change. The sim may not import `src/content`; the app passes a validated record in. `tests/guards/sim-purity.test.ts` and `content-boundary.test.ts` enforce it.

### Strict zod validation at the trust boundary with named errors
**Source:** `src/content/dock-port.ts:22-60` (lazy `?raw`, cached promise, `safeParse`, `where` path in message, named `DockPortError`); `src/content/ships.ts` `findShip` (named throw on missing key).
**Apply to:** every new generated record loader (per-kind dock-port, hull artifacts, station records). Never a silent fallback (O8).

### Content-build error idiom
**Source:** `tools/oolite-ingest/convert/dock-port.ts` `contentError("SCHEMA", file, key, { excerpt })`; output through `canonicalJson`.
**Apply to:** `stations.ts`, per-kind dock-port and hull emitters.

### Byte-identity discipline for Coriolis (Success Criterion 1)
**Source:** RESEARCH P1, B1-B7.
**Apply to:** all content and sim plans. After regeneration, `git diff --stat` on `public/models/coriolis.glb` and `src/content/generated/dock-port.json` must be empty; `ships-client.json` diff may only add entries; do not add a kind to `StationRecord`, the snapshot or `hashWorld` (station kind is a pure function of the system); no frozen file edited (`tests/acceptance/**`, `src/sim/ai/pilots/flight-script.ts`, `src/sim/ai/test-spawn.ts`); `tests/helpers/lave.ts` `laveFixture().layout` must not change values (feeds frozen `detectors.ts:1257-1262`). After any `src/sim/world/**` plan run `npm run test:acceptance` on the remote (21 of 21).

### Tripwire guard with synthetic positives
**Source:** `tests/guards/hull-wear-tripwire.test.ts`, `tests/guards/source-scan.ts`.
**Apply to:** the new station-constants guard; any deferred item (flashers O4, E-135 O6) gets a todo plus a guard, not silent omission.

### Docker/remote gates
Targeted: `docker compose run --rm test npx vitest run <file>`; full suite and e2e on the remote (`~/.claude/scripts/wegolite-remote-run.sh`); content regeneration `docker compose run --rm assets`, drift `docker compose run --rm assets npm run assets:check`.
