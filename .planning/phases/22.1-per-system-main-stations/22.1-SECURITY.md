# Phase 22.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Developer machine → remote test machine | Oolite reference container runs the station steps files and the measurement probe | Steps, probe world script, logs, reference pictures; outputs stay outside the repository |
| Pinned Oolite checkout → content build | `--export-pin` reads the station meshes and textures from pinned git blobs | Vendored bytes, checked against `pinned.sha256` |
| Compiled content → simulation and render | station records, dock records, static-hull artifacts and GLBs loaded at boot, arrival and Load | Game data; malformed or mismatched records must fail by name, never fall back to a Coriolis |
| Save (IndexedDB) → session | the saved station key is read back on Continue and F2 Load | Untrusted save data; checked against the catalogue allow-list |
