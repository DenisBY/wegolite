# Phase 22.1 Plan 03: Per-kind dock ports and hull octrees Summary

**Each station kind now has a dock-port record measured from its own dock mesh (Dodecahedron 210.362 x 81.0268 x 250, Icosahedron 82.1076 x 238.546 x 273.278) and its own lazily loaded hull-octree file, with validated per-kind loaders; the Coriolis dock record, the shared hull artifact and their goldens are byte-identical to 5deddef5.**

## Performance

- **Duration:** about 75 min
- **Tasks:** 2 (Task 1 tracer, Task 2 auto), both TDD-flagged
- **Files modified:** 22 (4 created generated files, 18 modified)

## Accomplishments

- Tracer: one path from `STATION_BUILDS` through `emitDockPorts`, the generated Icosahedron record, `loadStationDockPort`, `createDockGeometry` and the oracle comparison ran green; `Tracer verified end-to-end` (the Task 1 verify command, run before expanding).
- `emitDockPort` is gone; `measureDockPort(meshes, build)` and `emitDockPorts(meshes)` are the only dock-port emitter, so no second emitter can drift from the Coriolis bytes.
- Hull and contact boxes are unions over `hullModels` and `contactModels` (Pitfall P6): the Icosahedron hull covers `oolite_ico.dat` and `oolite_ico_hull.dat` (halfX/halfY 643.003, zMin -648.127).
- `emitStationHulls` writes one artifact per own-file kind through the same `serialise` path as the shared file; `staticSubentityKeys` now also asks for the new stations' subentity masses.
- The HUD guard reads the names of every `ships-static-hulls*.json`, so "Dodecahedron Station" and "Icosahedron Station" are checked against `MAX_MESSAGE_CHARS`.

- `MAX_STATIC_OCTREE_NODES` re-derived from 40,000 to 58,000. The Dodecahedron hull (41,913) failed the old cap at the first build; the largest octree measured is the Icosahedron's `oolite_ico_mainhull`, 47,529 (x 1.2 = 57,035, rounded up to 58,000). The schema comment names that number, the artifact (`ships-static-hulls-icosahedron.json`) and that the shared file's per-octree bound loosens with it (all three files share the schema). `MAX_STATIC_ARTIFACT_NODES` (104,000, driven by the shared file's 85,896) and `MAX_STATIC_HULL_ARTIFACT_BYTES` (270,000) did not move.
- Names compiled from shipdata: "Dodecahedron Station", "Icosahedron Station". Each hull's `collisionRadius` equals its `ships-client.json` entry (832.2093505859375, 940.7927856445312); both are not frangible.
