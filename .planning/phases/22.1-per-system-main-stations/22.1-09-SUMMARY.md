## Accomplishments

### Load points

| Entry point | Behaviour |
| --- | --- |
| Boot (New game, Continue) | After `stationFor` for the starting system, `await ensureStationHulls(ctx, station.kind)` inside the same `try` as the station records, so a failed artifact is on the boot-failure surface and nothing is installed; before the first `scenes.enterSystem`. |
| F2 Load | After the saved system lookup and before the derive/install block, with traffic on, `await ensureStationHulls(ctx, savedSystem.station)`; then the G-8 checks run again (disposed, save screen open, same generation) and return; a rejection goes to `failLoad("Save could not be loaded")` before any live reference moves. First steps after a Load are deterministic. |
| Hyperspace countdown | `hyperspaceCountdownStarted` is also routed to `hyperspaceFlow` (after `hudMessages`), which calls the injected `prefetchStation(destinationId)` = `prefetchStationFor(ctx, galaxyById, id)`: about 15 s before the arrival. |
| Hyperspace arrival | `handleHyperspaceJumped` calls `prefetchStationFor` once more after the install block (a no-op when present). The swap never awaits it: an arrival that beats the load has no hull for the station until the merge lands (the existing no-hull rule: no laser candidate). |

`ensureStationHulls` (station-install.ts): no-op with traffic off or before the hull table exists, and when the kind's ship key is already in the table (the Coriolis, a repeat visit); otherwise one in-flight promise per kind per session (a `WeakMap` keyed by the session state), `loadStationHulls(kind)`, then, unless `ctx.runtime.disposed`, `mergeStationHulls` into a new `ctx.core.hulls` and the artifact's names added to a copy of `ctx.core.targetNames`. A rejection leaves the session as it was and the next ask loads again. `prefetchStationFor` logs a rejection once per prefetch with the file name via `console.error` and swallows it.

The hit rule and the ident lock stay as plan 22.1-06 left them: `identLocked` carries `staticIdentKey(row, layout)` (the layout's `stationKey`), and the HUD shows the name found under that key in `ctx.core.targetNames`, the same map the Coriolis name comes from; the new test dispatches the lock for each kind before and after the merge and gets the raw key, then the compiled name.
