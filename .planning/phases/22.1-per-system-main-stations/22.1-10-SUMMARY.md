## Albedo luminance against the clipping bound

Method: Rec. 709 luma of the sRGB bytes of every texel of the vendored diffuse PNG, rounded to a byte. The same script reproduces the recorded Cobra figures in `src/render/exposure.ts` exactly (mean 57, p90 101, p99 126, max 225), so the definition matches. Bound: `clippingAlbedoByteFor(OOLITE_REFERENCE_NDOTL)` = 119 (101 at NdotL 1.0, 139 at 0.5). The Coriolis constant `OOLITE_REFERENCE_ALBEDO_BYTE` is 87; the same script gives its hull map a mean of 91.1 (its other maps 64.8 to 78.0), so the recorded 87 is a different weighting and the hull figure is shown for scale only.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `.dat` NAMES applied positionally, unlike Oolite**
- **Found during:** Task 1 (first `assets` run: `ship "oolite_dodo_faceplate" has no material "auvBG.tga"`)
- **Issue:** `oolite_dodo_faceplate.dat` authors `NAMES 1 / auvBG.tga` over a file-name `TEXTURES` key. Oolite applies each NAMES line as `renameTexturesFrom: "<j>" to: name` (`OOMesh.m:1387-1390`), which only renames a material whose key is the decimal text `j`; the parser renamed by first-appearance index, so the faceplate material became `auvBG.tga` and matched no shipdata material.
- **Fix:** `renamedMaterial` in `dat.ts` renames only numeric keys (`names[Number(key)]`). Every existing model is unchanged: the build output of all 38 other GLBs and every generated file was byte-identical after the change. Test added in `dat.test.ts` (faceplate keeps its file-name key; the Icosahedron front section key `0` is named).
- **Files modified:** `tools/oolite-ingest/convert/dat.ts`, `tools/oolite-ingest/convert/dat.test.ts`
- **Committed in:** `a30a218d`

**2. [Rule 3 - Blocking] Tool-test expectations tied to the old mesh and texture counts**
- **Found during:** Task 1 verification
- **Issue:** `textures.test.ts` (110 names, emissive set), `texture-encode.test.ts` (35 normal and 28 specular maps) and `ship-mass.test.ts` (the 32-mesh table) pinned the pre-phase data.
- **Fix:** deliberate edits after confirming the diff was only the new stations (126 names, 41 normal and 32 specular maps, the table excluding the new stations' meshes).
- **Files modified:** the three test files above
- **Committed in:** `a30a218d`, `66ac1be4`
