## Sampling Rate

- **After every task commit:** the task's targeted `npx vitest run <files>`, plus `docker compose run --rm typecheck` and `docker compose run --rm lint`
- **After every plan wave:** remote full suite; for any plan touching `src/sim/world/**`, the remote 20-seed acceptance run (`npm run test:acceptance`, 21 of 21)
- **Before `/gsd-verify-work`:** remote `verify-full` green, and `tests/e2e/stations.spec.ts` green
- **Max feedback latency:** 120 seconds for targeted runs
