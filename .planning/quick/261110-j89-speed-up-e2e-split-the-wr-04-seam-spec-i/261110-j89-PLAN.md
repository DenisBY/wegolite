# Quick task 261110-j89: split the WR-04 seam spec out of the default Playwright config

Executed inline by the main agent at the owner's request, on a dedicated branch.
Implements recommendations 1 and 2 of the 2026-11-10 test-speed review.

## Why

`playwright.config.ts` declared two `webServer` entries. Playwright starts every
entry before any test, regardless of spec selection, so the second entry
(`npx vite build -c vite.seams.config.ts` on 127.0.0.1:4175) was a second full
Vite build on every Playwright run — including the `verify` fast gate and
single-spec invocations — while only `tests/e2e/hyperspace-failure.spec.ts`
ever used port 4175.

`reuseExistingServer: !process.env.CI` cannot help the local loop either: the
Dockerfile bakes `CI=1` into the image, so it evaluates to `false` in every
container.

## Tasks

1. Move the seam build and its 4175 preview into `playwright.seams.config.ts`,
   with `testMatch` for the seam spec and no `projects` (Chromium by default,
   D-09). Keep `reuseExistingServer: false` there: the WR-04 positive control
   needs a freshly built test-only bundle.
2. Add `testIgnore` for the seam spec to `playwright.config.ts`, drop the second
   `webServer` entry, and keep `workers: 2`, `fullyParallel: false` and the
   D-08 trace/screenshot posture untouched.
3. Compute `reusePreview` as `WEGOLITE_REUSE_PREVIEW === "1" || !process.env.CI`
   and use it on the remaining 4173 server. CI stays `false`.
4. Add `test:e2e:seams` to `package.json`; append it to the `e2e` and
   `verify-full` chains (the `verify` fast gate is unchanged and now needs only
   one build). Do not add a Compose service (FOUND-09).
5. Update the container contract pins, add a guard for the split, and update
   `vite.seams.config.ts`, README, CHANGELOG and the Key Decisions table.

## Verification

Docker only: `typecheck`, `lint`, `test`, a targeted seam-spec run,
`verify` (fast gate) and ideally `verify-full` (release gate, CI runs it).
