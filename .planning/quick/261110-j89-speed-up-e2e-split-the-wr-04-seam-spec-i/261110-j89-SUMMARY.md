# Quick task 261110-j89: split the WR-04 seam spec out of the default Playwright config

dedicated branch `perf/e2e-seam-config-split`. Executed inline by the main agent

## Why recommendation 2 needed an explicit opt-in

`reuseExistingServer: !process.env.CI` is the documented Playwright pattern, but
the Wegolite Dockerfile bakes `CI=1` into every container, so the literal form
evaluates to `false` everywhere and cannot speed up the local loop. The config
therefore keeps the literal pattern and adds `WEGOLITE_REUSE_PREVIEW=1` as an
explicit opt-in:

```ts
const reusePreview =
  process.env["WEGOLITE_REUSE_PREVIEW"] === "1" || !process.env["CI"];
```

CI keeps reuse off, so a stale server fails loudly. Compose services do not share
a network namespace, so the reused preview must be started by `npm run preview`
in the same container as Playwright; a `docker compose up preview` server is not
visible at `127.0.0.1:4173` from another container.
