# Quick task 261110-c4d: use the specular map colour

Executed inline by the main agent at the owner's request. Item P8 of
`.planning/reviews/2026-11-09-logic-security-review.md`, colour half only.

Oolite multiplies the specular colour by the map's RGB
(`oolite-default-shader.fragment:433`). The GLB writer named the map only as
`KHR_materials_specular.specularTexture`, which reads alpha, so the RGB was
downloaded and ignored. The writer now also emits `specularColorTexture` with
the same texture index and a `specularColorFactor` of `[1, 1, 1]`.

Not in scope: Oolite uses the map's alpha as gloss, and the client still reads
it as strength (the D-08 approximation). Mapping it to roughness needs a baked
texture and belongs to a look pass.
